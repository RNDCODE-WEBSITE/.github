# R&D Code

**R&D-студия для ранних стадий hardware.** Помогаем довести идею устройства до работающего прототипа:
прошивка, плата, приложение и документация, которую может подхватить другая команда.

## Что мы делаем

- **Прошивки и встраиваемые системы** — ESP32, STM32, bare metal и RTOS: драйверы, радио, OTA.
- **Проектирование плат** — схемотехника, 2–4 слоя, DFM-проверка, запуск и измерения.
- **Приложения** — Windows, Linux, macOS, а также Android и iOS: управление устройством, телеметрия, дашборды.

Только исследования и MVP — серийное производство не берём.

## Как начать

1. Пришлите один абзац о задаче и дедлайн.
2. В ответ получите объём работ, риски и сроки.
3. Стартуем со спринта валидации или сразу с прототипа.
